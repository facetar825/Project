# Rogil — Зал трёх печатей

Учебный 3D-рогалик на Godot: один законченный этаж с автоматическим боем, опытом, случайным выбором улучшений и боссом. Ориентир по игровому циклу — Megabonk. Данж собран из авторских пресетов комнат исходного проекта.

## Запуск

1. Установить Godot **4.6 или новее**, обычную версию, без .NET.
2. Импортировать **`app/rogil/project.godot`**. Дождаться импорта моделей.
3. Нажать **F6** в сцене `Scene/Floor.tscn` или **F5** для запуска проекта.
4. Нажать «Начать забег».

Рабочая версия — `app/rogil`. Каталог `app/rogil-(4.6)` — исходная копия, изменения этажа туда не дублируются. Прежние сцены сохранены; стартовой стала `Scene/Floor.tscn`.

## Управление

- **WASD** — движение относительно камеры.
- **Мышь** — вращение камеры.
- **Shift** — рывок с короткой неуязвимостью; восстановление 2,5 секунды.
- **Пробел** — прыжок.
- **Esc** — пауза и освобождение курсора.
- Атака — автоматически по врагам рядом. Осколки опыта притягиваются с расстояния 7 метров.

## Прохождение

Маршрут: входной коридор (`com_one`) → длинная галерея (`room_4`) → каменный зал (`roomtree`) → лабиринт (`comtwo`) → зал босса (ещё один `roomtree`, повёрнутый на 90°).

В первых трёх комнатах — 10, 16 и 22 противника. Бой начинается только после входа в комнату, проход назад закрывается печатью. Обычные враги, быстрые разведчики и медленные тяжёлые стражи отличаются здоровьем, скоростью и уроном. После зачистки загорается печать, восстанавливается 25 HP, через 5 секунд открывается следующая дверь. До следующего боя нужно самостоятельно пройти в следующую комнату. Оставшийся опыт притягивается к герою.

Враги обходят перегородки по сетке AStarGrid2D, построенной по реальным коллизиям пресетов. Удары героя и врагов не проходят через стены. Незначительные перепады пола у стыков перекрыты порогами, а лишняя высота старых дверных порогов исправляется при запуске.

При повышении уровня бой останавливается: нужно выбрать одно из трёх случайных улучшений. Всего пять вариантов — урон, частота атаки, здоровье, радиус атаки и скорость.

После лабиринта нужно войти в последний зал, где появится босс с 850 HP. Каждые пять секунд он готовит удар радиусом 7 метров: за 1,5 секунды нужно выйти из красного круга или использовать рывок. После победы откроется бирюзовый портал у дальней стены. **Для завершения этажа нужно войти в портал.** После смерти и победы доступны новый забег и главное меню.

## Устройство проекта — для пояснения на защите

- `Script/floor/floor.gd` — управление состояниями (меню, бой, улучшение, пауза, победа, поражение), волны, опыт, интерфейс и результат.
- `Script/floor/hero.gd` — движение, камера, рывок, здоровье и автоматическая атака.
- `Script/floor/foe.gd` — три типа врагов и босс с предупреждением перед ударом.
- `Script/floor/visuals.gd` — общие функции построения геометрии, колец и надписей.
- `Scene/Floor.tscn` — входная сцена игры, интерфейс и управление забегом.
- `Scene/PresetDungeon.tscn` — готовая сборка из экземпляров исходных комнат; её можно открыть в 3D-редакторе Godot и осмотреть весь маршрут.
- `Script/floor/dungeon.gd` — стыковка по маркерам `pointgena`, печати дверей, проверка пола и маршруты врагов. При запуске положение комнат уточняется по маркерам пресетов.
- `Script/floor/art.gd` — оформление комнат: колонны, бронзовые пояса, ковёр, знамёна, напольные знаки, мерцающие факелы и частицы. Декор не добавляет препятствий.
- `Shader/dungeon_stone.gdshader` — процедурная кладка и плитка без дополнительных текстур; работает в режиме Compatibility.

Модель героя, анимации, комнаты, стены, полы и дверные рамы взяты из исходного проекта. Оригинальные сцены комнат не изменены: используются связанные экземпляры PackedScene. При запуске поверх пресетов применяется единое оформление из тёмного камня и бронзы. Противники — каменные стражи из простой геометрии со светящимися глазами и движением ног. Один фиксированный этаж; случайны позиции появления врагов и предлагаемые улучшения. Сохранений, других этажей, инвентаря и постоянной прогрессии нет.

## Проверка

Из каталога репозитория, если `godot` доступен в PATH:

```powershell
godot --headless --path app/rogil --editor --import --quit
godot --headless --path app/rogil --script res://tests/floor_smoke.gd
godot --headless --path app/rogil --script res://tests/dungeon_presets.gd
```

Интеграционные проверки покрывают бой, улучшения, смену комнат, босса, победу, смерть и перезапуск. Отдельная проверка данжа проводит физическое тело героя через каждый дверной стык, проверяет закрытые печати, доступность точек появления и движение врага в обход стены лабиринта. Сложность и удобство управления стоит дополнительно оценить обычным прохождением.

`tests/capture_floor.gd` запускается без `--headless` и сохраняет снимки меню и игры в `user://`. В старых FBX есть ссылки на отсутствующие текстуры: редактор может сообщать об этом при первом импорте. На новом этаже герой использует собственный материал, а старые модели с этими текстурами не используются.
